# Security Policy

We take the security of our platform seriously. If you believe you have found a security vulnerability, please read this document to learn how to report it responsibly.

---

## Supported Versions

Only the latest release version on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

Please do not report security vulnerabilities via public GitHub issues. Instead, report them privately:

1. Send an email to **security@platform.local** (or the project maintainer's contact).
2. Include a detailed description of the vulnerability, steps to reproduce, and any proof-of-concept (PoC) code or scripts.
3. We will acknowledge receipt of your report within 48 hours and work with you to analyze and remediate the issue.

---

## Responsible Disclosure Policy

* Give us reasonable time to investigate and fix the vulnerability before disclosing it publicly.
* Do not exploit the vulnerability to view unauthorized data, disrupt services, or compromise user accounts.
* We follow a 90-day disclosure policy; once a fix is released or 90 days have elapsed, the vulnerability may be disclosed.
